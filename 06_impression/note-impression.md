# Note pour l'imprimeur — Bâche 2 m × 3 m

## Fichier livré

- `03_bache/bache-haute-resolution-50dpi.png` (6000 × 4000 px)
- `03_bache/bache-haute-resolution-50dpi.jpg` (6000 × 4000 px)

## Dimensions

- Format final : **3000 mm × 2000 mm** (3 m × 2 m)
- Orientation : paysage
- Fond perdu : prévoir 50 mm de fond perdu sur chaque côté si l'imprimeur le demande (pas inclus dans le fichier actuel)

## Résolution

- Fichier à **6000 × 4000 px**, soit **50 dpi** à taille réelle.
- C'est acceptable pour une bâche vue de loin (> 2 m).
- Si l'imprimeur demande plus, on peut fournir en **9000 × 6000 px (75 dpi)** sur demande.

## Couleurs

- Le fichier est en RVB. Vérifier avec l'imprimeur s'il faut convertir en CMJN.
- Couleurs principales :
  - Bleu `#0047AB`
  - Rouge `#C41E3A`
  - Blanc `#FFFEF9`
  - Or `#BFB33B`
  - Vert `#4A7C2A`
  - Noir texte `#222222`

## Visuel à remplacer

- Le bloc gris au centre est un emplacement réservé pour le visuel IA.
- Une fois le visuel généré (prompt P1 dans `05_prompts_ia/prompts-ia.md`), il faut l'insérer dans ce bloc.
- Dimensions de l'emplacement : environ 3560 px × 1640 px dans le fichier 6000×4000.

## Support d'impression

Options à discuter avec l'imprimeur :
- Bâche PVC 340 g/m² (standard, résistante, brillante)
- Bâche tissu (micro-perforé ou Backlight si éclairage arrière)
- Papier grand format 120 g/m² (moins cher mais moins durable)
- Vinyle adhésif (si fixation sur mur lisse plutôt que suspension)

## Finitions

- Œillets tous les 50 cm pour fixation murale
- Ourlet renforcé
- Pas de pli
